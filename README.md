### 🌊 The Flow Productivity &amp; Systems Ecosystem

A signature collection of native applications engineered for zero bloat, low latency, and high-precision developer and creator workflows.

```
  ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
  │   ✦ CueFlow     │  ───  │  ⚡ ScreenFlow   │  ───  │   🖋️ InkFlow     │
  │ Mobile Telecue  │       │ Ultra-Low Mirror│       │ S Pen Annotate  │
  │ React Native/TS │       │  C# & Kotlin    │       │ Native Android  │
  └─────────────────┘       └─────────────────┘       └─────────────────┘
```

#### 1. [CueFlow — Professional Android Teleprompter](https://github.com/shaniraj4587/CueFlow)
* **Core Stack**: `TypeScript` • `React Native` • `Android SDK`
* **Architecture Highlights**: Offline-first mobile teleprompter application engineered for flawless keynotes, video broadcasts, and presentations. Features smooth variable-rate text scrolling, mirror display rendering, script management, and optimized multi-architecture release packages (`arm64-v8a` / universal APKs).
* **Source**: [`github.com/shaniraj4587/CueFlow`](https://github.com/shaniraj4587/CueFlow)

#### 2. [ScreenFlow — Ultra-Low Latency Screen Mirroring &amp; Whiteboard](https://github.com/shaniraj4587/Screenflow)
* **Core Stack**: `C# (.NET)` • `Kotlin` • `Windows 11` • `Android`
* **Architecture Highlights**: High-performance, sub-15ms screen mirroring system bridging Android tablets (optimized for Samsung Galaxy Tab S9 FE &amp; S Pen) and Windows 11 laptops over physical USB or Wi-Fi. Features zero-trust mutual authentication, hardware-accelerated stream decoding, and low-latency stylus digitization.
* **Source**: [`github.com/shaniraj4587/Screenflow`](https://github.com/shaniraj4587/Screenflow)

#### 3. [InkFlow — Minimal Screen Pen &amp; Native Annotation App](https://github.com/shaniraj4587/InkFlow)
* **Core Stack**: `Kotlin` • `Android Jetpack` • `Hardware Canvas API`
* **Architecture Highlights**: Ultra-lightweight (1.82 MB), zero-bloat native Android screen overlay and drawing system inspired by Epic Pen and Samsung Notes. Engineered for low-latency S Pen ink tracking, smooth Bézier vector smoothing, and an intuitive floating canvas HUD.
* **Source**: [`github.com/shaniraj4587/InkFlow`](https://github.com/shaniraj4587/InkFlow)
